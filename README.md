# Mosthdfa - مساعد الشهادة السودانية

واجهة عربية لحل أسئلة الشهادة السودانية عبر:

- كتابة السؤال مباشرة.
- رفع صورة السؤال واستخراج النص عربيًا وإنجليزيًا داخل المتصفح.
- اختيار المادة ونوع الإجابة والشرح المرئي بالخطوات.
- توليد حل فعلي من خادم آمن عبر OpenAI.

## التشغيل المحلي

يتطلب Node.js إصدار 18 أو أحدث.

```bash
export OPENAI_API_KEY="ضع-مفتاحك-هنا"
export OPENAI_MODEL="gpt-4o-mini" # اختياري
npm start
```

ثم افتح `http://localhost:8080`.

على Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="ضع-مفتاحك-هنا"
npm start
```

لا تضع المفتاح في `app.js` أو في المستودع.

## مسار الذكاء الاصطناعي

ترسل الواجهة الطلب إلى `POST /api/answer` بالصيغة:

```json
{
  "question": "نص السؤال",
  "subject": "رياضيات",
  "stage": "الشهادة السودانية",
  "answerType": "شرح وتفصيل",
  "verify": true
}
```

ويعيد الخادم JSON يحتوي على `title` و`sections` و`steps`.

## الدقة والمناهج

الخادم لا يكتفي بعرض جواب تجريبي عند توفر المفتاح، لكنه لا يحتوي وحده على قاعدة منهج سوداني محدثة أو محتوى مرخصًا. للإطلاق النهائي يلزم إدخال الكتب والمناهج المعتمدة في نظام RAG مع المراجع، وفحص الإجابات من معلمين مؤهلين، وتسجيل الأخطاء والاعتماد على رقم نسخة المنهج.
