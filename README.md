# Mosthdfa - مساعد الشهادة السودانية

واجهة عربية جاهزة لحل أسئلة الشهادة السودانية عبر:

- كتابة السؤال مباشرة.
- رفع صورة السؤال واستخراج النص عربيًا وإنجليزيًا داخل المتصفح.
- اختيار المادة ونوع الإجابة والشرح المرئي بالخطوات.
- ربط واجهة آمنة بخادم ذكاء اصطناعي عبر مسار `/api/answer`.

## التشغيل المحلي

لأن الواجهة لا تحتاج إلى Node لتشغيلها، افتح `index.html` مباشرة أو شغّل خادمًا بسيطًا:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الربط بذكاء اصطناعي

واجه التطبيق ترسل الطلب إلى نقطة نهاية POST في `/api/answer` بالصيغة التالية:

```json
{
  "question": "نص السؤال",
  "subject": "رياضيات",
  "stage": "الشهادة السودانية",
  "answerType": "شرح وتفصيل",
  "verify": true
}
```

يجب أن يعيد الخادم:

```json
{
  "title": "عنوان الحل",
  "sections": [{"heading": "العنوان", "text": "النص"}],
  "steps": ["الخطوة الأولى", "الخطوة الثانية"]
}
```

احتفظ بمفاتيح مزود الذكاء الاصطناعي على الخادم، ولا تضعها داخل JavaScript أو المستودع.

## مهم

لا توجد قاعدة منهجية مضمونة الأمان في واجهة العرض وحدها. للإجابات الدقيقة، يحتاج المشروع إلى قاعدة بيانات للمناهج السودانية المعتمدة، ومراجعة بشرية، ونظام منع الإخطاء والتأكد من المراجع.
